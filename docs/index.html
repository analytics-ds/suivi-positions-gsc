Comment lire ces chiffres
  • La Search Console donne une position moyenne pondérée par les impressions, pas un rang mesuré à un instant T comme un rank tracker.
  • Un jour sans impression n'a pas de donnée : la courbe s'interrompt, ça ne veut pas dire une position à 0.
  • Les 3 derniers jours sont provisoires et sont réécrits avec la donnée consolidée aux runs suivants.
  • Seules les impressions de la page suivie sont comptées. Si une autre URL du site ranke sur le mot-clé, elle n'apparaît pas ici.
